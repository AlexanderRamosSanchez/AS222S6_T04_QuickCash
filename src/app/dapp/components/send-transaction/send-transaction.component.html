¿Qué es la función sendTransaction?

Esta función permite enviar ETH o tokens a otra dirección. Puedes elegir entre:

  • Envío Directo: Transfiere ETH directamente a la dirección del destinatario.
  • Usar Contrato: Utiliza el contrato inteligente para realizar la transferencia, lo que puede incluir lógica adicional.

Los campos requeridos son:

  • Destinatario: La dirección de wallet que recibirá los fondos. Puedes seleccionar un contacto existente o añadir uno nuevo.
  • Cantidad: El monto a enviar en {{ etherService.getNetworkCurrency() }}.

Nota: Las transacciones en blockchain son irreversibles. Verifica cuidadosamente la dirección del destinatario antes de enviar.
