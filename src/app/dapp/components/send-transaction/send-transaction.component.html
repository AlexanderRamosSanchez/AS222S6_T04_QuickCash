¿Qué es la función sendTransaction?

Esta función permite enviar {{ etherService.getNetworkCurrency() }} a otra dirección. Puedes elegir entre:

  • Envío Directo: Transfiere {{ etherService.getNetworkCurrency() }} directamente a la dirección del destinatario.
  • Usar Contrato: Utiliza un contrato inteligente para realizar la transferencia, lo que puede incluir lógica adicional y seguridad.

Modo Contrato

Al usar el contrato, puedes:

  • Inicializar: Conectar con un contrato existente.
  • Depositar: Añadir fondos al contrato para usar más tarde.
  • Enviar: Transferir fondos desde el contrato al destinatario.

El contrato proporciona una capa adicional de seguridad y funcionalidad.

Gestión de Contactos

Para facilitar transacciones recurrentes, puedes:

  • Seleccionar contactos: Elige entre tus contactos guardados.
  • Añadir contactos: Guarda nuevas direcciones con nombres y notas.
Importante: Las transacciones en blockchain son irreversibles. Verifica cuidadosamente la dirección del destinatario y el monto antes de enviar.
